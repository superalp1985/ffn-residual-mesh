The downloaded file was verified in place:

```text

bytes: 16,464,440,224
sha256: 322e194ff79741c7baa497c240f677f54b201b0efab44ca8e50f122b39123482
ffn tensors: 192 (64 layers x gate/up/down)
dimensions: hidden=5120, ffn=17408, layers=64
```

This is a mixed `Q4_K_M` file, not a file in which every tensor is literally
`Q4_K`. The 192 FFN tensors were reported as:

```text
IQ4_XS=85, Q5_K=50, Q4_K=38, Q3_K=7, IQ4_NL=6, IQ3_S=4, Q6_K=2
```

The machine-readable record is
`results/qwen38_27b_download_manifest.json`. It is generated by
`scripts/validate_qwen38_manifest.py` and intentionally records the original
GGUF as the exact cold-start fallback. No runtime radix lookup table is
required by this manifest.

Download requirements:

```text
at least one complete Q4_K or Q4_K_M GGUF
one matching tokenizer set
one matching config.json
```

Do not download a separate partial GGUF shard unless all shards are placed in
the same directory. FDM may be used for `.../resolve/main/...` file URLs.
