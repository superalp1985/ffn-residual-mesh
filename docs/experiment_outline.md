# 前馈层实验大纲

日期：2026-09-02

## 1. 目标

验证以下命题：

1. FFN 输出是否存在可利用的状态局部性。
2. 预计算基础输出是否能覆盖大部分 FFN 输出能量。
3. 剩余误差是否可以用低秩、分块或稀疏算子近似。
4. 逻辑分页加超级块搬运是否能降低有效 PCIe 流量和同步次数。
5. 在误差受控时，端到端推理是否比完整 GPU FFN 更快或更省显存。

当前试验模型是 Qwen3.5 2B Q4_K_M。GGUF 元数据显示它是 `qwen35` 混合结构，24 层、hidden size 2048、FFN intermediate size 6144，并包含 SSM/线性注意力张量；因此首轮 FFN 实验要按层记录 Attention/SSM 类型，不能假设所有 block 相同。

## 2. 工作假设

标准 FFN：

```text
F(x) = W2 * activation(W1 * x + b1) + b2
```

状态查表与残差校正：

```text
k = route(x)
F_hat(x) = M[k] + U * diag(alpha[k]) * V^T * (x - c[k])
```

其中 `M[k]`、`c[k]`、`alpha[k]` 可离线生成，`U/V` 尽量跨状态区域共享。

分块线性查表候选：

```text
x = [x1, x2, ..., xm]
W1*x ~= sum_j table[j, quantize(xj)]
```

非线性交叉项不丢弃，进入残差或精确回退。

## 3. 实验阶段

### 阶段 A：运行环境基线

- 确认 CPU、GPU、CUDA、PCIe、llama.cpp 版本。
- 对 Qwen3.5 2B Q4_K_M 跑 CPU、GPU、混合层数基线。
- 记录 prompt、decode、显存、吞吐、首 token 延迟和功耗（可得时）。

### 阶段 B：FFN 可压缩性扫描

- 获取可观测的 FFN 输入、门控输出和 FFN 输出。
- 按层统计相邻 token 差分、PCA 有效秩、聚类失真和残差能量。
- 分开统计 prefill 与 decode，先以 batch=1 decode 为主。

### 阶段 C：算子展开原型

- `K=1`：单中心查表。
- `K=16/64/256`：状态分区查表。
- 残差 rank 测试：`r=16/32/64/128`。
- 共享基底、分层基底和每区域基底对比。
- 加入残差阈值和精确 FFN 回退。

### 阶段 D：分页和块搬运

- 逻辑页：4KB/16KB/64KB，仅作为索引单位。
- 搬运超级块：256KB、1MB、4MB、16MB 对比。
- 使用 pinned host ring buffer、双缓冲和异步 H2D。
- 统计请求合并率、实际搬运字节、PCIe 往返次数和同步等待。

### 阶段 E：端到端验证

- 单层误差：相对 L2、余弦相似度、最大分量误差。
- 模型误差：next-token KL、logit 误差、困惑度或任务准确率。
- 系统指标：首 token、tokens/s、显存峰值、CPU 占用、RAM 占用。
- 每层可独立选择查表、低秩残差、LUT 或完整 FFN。

## 4. 首轮验收门槛

以下是工程门槛，不是理论结论：

- 查表加残差的输出误差明显低于纯查表。
- 小 rank 残差能覆盖主要误差能量。
- 超级块搬运的有效带宽高于细粒度随机搬运。
- CPU 分类和同步开销没有吃掉 FFN 节省。
- 异常输入可稳定回退，不出现误差级联失控。

## 5. 失败条件

- 输入状态没有局部性，任何合理 `K` 都需要接近完整表。
- 残差 rank 接近 `d_model`，无法减少计算。
- CPU/RAM 查表导致每层同步，端到端延迟反而增加。
- 校准分布外输入频繁触发精确回退。
