# 2026-09-02 Iteration 3

## 研究前置

本轮先查了自适应近似推理、OOD 置信度门控和 TARDIS 式分段线性回退。共同做法是：近邻/低误差区域走近似，低置信度样本回退精确算子；因此本轮验证“距离门控 + 完整 FFN 回退”，不把近似结果强行覆盖所有 token。

## 留出集

- 训练：16 组主题提示，约 275 token/层。
- 测试：新增 4 组未参与拟合的提示，75 token/层。
- 代表层：0、10、18、22、23。

## 加性 LUT 留出结果

`ffn_swiglu` 分块、每块 K=8、输出向量坐标下降拟合：

| layer | 留出相对 L2 | 留出余弦 |
|---:|---:|---:|
| 0 | 0.820 | 0.527 |
| 10 | 0.886 | 0.539 |
| 18 | 0.831 | 0.583 |
| 22 | 0.751 | 0.671 |
| 23 | 0.383 | 0.914 |

校准集内的 0.19 到 0.46 不能直接作为上线指标；留出后只有 layer 23 显示出较稳定的局部结构。

## 距离门控

对 `ffn_swiglu` 分块中心距离排序，低距离 token 走加性 LUT，其余精确回退：

- layer 23：近似 25% 时预计整体相对 L2 约 0.070；近似 50% 时约 0.156。
- layer 22：近似 25% 时约 0.120；近似 50% 时约 0.319。
- layer 10/18：近似 10% 时约 0.03；近似 25% 时约 0.13 到 0.16。

距离与真实误差相关系数约 0.60 到 0.73（layer 0 只有 0.27），说明距离可作为第一版 OOD 信号，但必须按层校准阈值。

## 判断

加性 LUT 可以作为“少量 token 的快速路径”，不适合作为全量 FFN 替换。下一步优先做：

1. 只对后层和低距离 token 启用，保留精确回退。
2. 将 `ffn_swiglu` 的块表与 `ffn_down` 权重布局绑定，估算真实 H2D 搬运字节。
3. 评估连续 token 路由的块合并率，避免每个 token 单独 DMA。
