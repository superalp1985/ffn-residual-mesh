# 2026-09-02 Iteration 4

## 研究前置

本轮检索了时间残差预测、局部分段线性和向量量化残差重建。采用两条候选：

- 时间残差：上一 token 输出加低秩 `B(x_t-x_{t-1})`，配合周期性精确回退。
- 加性 LUT + 连续残差：先按 `ffn_swiglu` 分块查表，再对块量化误差拟合共享低秩校正。

## 时间残差结果

留出集上，除 layer 23 外误差快速累积；layer 23 即使 rank=128、每 2 token 精确回退，近似 token 误差约 0.33，整体约 0.16。每 4/8 token 回退后整体误差迅速升高。

结论：不作为主路径。它适合作为未来“短窗口预测”实验，不适合长序列连续累积。

## 状态中心留出结果

在输入 `x` 上训练 K=16/64 中心、共享低秩残差，留出误差普遍高于 `ffn_swiglu` 加性 LUT；layer 23 的 K=64、rank=128 仍约 0.55。

结论：路由应尽量靠近非线性之后，不能只对原始 FFN 输入做全局中心化。

## 加性 LUT + 残差

在 `ffn_swiglu` 上按 256 维切块、每块 K=8：

| layer | lookup | +rank16 | +rank64 | +rank128 |
|---:|---:|---:|---:|---:|
| 0 | 0.822 | 0.813 | 0.787 | 0.758 |
| 10 | 0.884 | 0.876 | 0.859 | 0.843 |
| 18 | 0.830 | 0.820 | 0.802 | 0.782 |
| 22 | 0.764 | 0.755 | 0.733 | 0.711 |
| 23 | 0.389 | 0.372 | 0.360 | 0.352 |

残差能改善，但不是数量级改善；layer 23 仍是最有希望的候选层。

## 分页窗口模拟

对 24 个 `ffn_swiglu` 块、每块 K=8、每个输出向量 4 KiB 的表，连续窗口内单 token 请求会触及多个超级块；256 KiB 超级块下平均传输仍接近整张表。block-major 与 code-major 在当前路由分布上没有明显差异。

结论：不要把每个 token 的 LUT 输出表当作 GPU 页缓存。更合理的路径是 CPU/RAM 完成查表，只把最终 2048 维结果或低秩残差送 GPU；超级块分页主要服务精确 FFN 权重和残差基底。
