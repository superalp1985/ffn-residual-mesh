# 2026-09-03 Iteration 15

## 目标

验证 Chebyshev 基础公式是否只对末层有效，并初步建立分层算子选择表。

## 调研与方法

参考分层混合精度/自适应推理路线，继续采用逐层独立拟合和精确回退，不假设相邻层共享 degree、bound 或 residual rank。测试 Chebyshev degree=4/5，bound=5/6σ。

## 基础项扫描

| 层 | 最佳配置 | 留出输出 rel-L2 |
|---|---|---:|
| 0 | degree=4, B=5 | 0.0905 |
| 10 | degree=4, B=5 | 0.0328 |
| 18 | degree=4, B=6 | 0.0751 |
| 22 | degree=4, B=6 | 0.0500 |
| 23 | degree=5, B=5 | 0.0232 |

## 残差链路

layer 10 使用 degree=4、B=5、capture-target 残差：

- 基础项留出误差：`0.03283`。
- output_rank=64 时：`0.03231`。
- output_rank=4 时：`0.03286`，说明该层残差也可压到很小的 GPU 基底。
- down 权重代理为 `7,077,888 B`，比 layer 23 更小，但仍远大于近似包约 `4.1 KiB/token`。

layer 0/18 的基础项误差已经较高，暂不接近似残差；优先保留精确 FFN。

## 初步分层策略

```text
layer 10: Chebyshev degree=4, B=5 + sparse residual
layer 22: Chebyshev degree=4, B=6 + strict threshold/fallback
layer 23: Chebyshev degree=5, B=5 + sparse residual
other scanned layers: exact fallback until separately calibrated
```

## 结论

1. “分层选择公式”显著优于全局统一参数；同一模型中 layer 0、18、22、23 的最优误差差异很大。
2. 目前可进入系统原型的候选层至少有 10、22、23，但 layer 22 仍需更严格误差门槛。
3. 近似层集合应由离线验证生成 manifest，运行时只按 layer_id 读取对应公式和阈值。
