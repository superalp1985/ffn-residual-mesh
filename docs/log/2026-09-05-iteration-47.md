# 2026-09-05 Iteration 47: Phone FFN Loopback Protocol

## 调研前提

- ComfyUI、TeaCache 和 SageAttention 继续留在中心模型执行链；手机只作为可选 FFN base worker。
- H3 的精确 gate/up 返回仍受 packed sequence rows 和链路带宽限制，不能把普通 Wi-Fi 当作默认实时路径。

## 实现

- 新增 `src/phone_ffn_loopback.py`。
- 帧包含 run/step/block/tile/row 元数据、payload 长度和 CRC32。
- worker 按输出行分片并发处理；中心调度器按 deadline 收集结果。
- 超时、分片不匹配或 checksum/protocol 错误均显式进入 GPU 精确 fallback。
- 新增 3 个 unittest，验证 framing、checksum、并发排序和 deadline fallback。

## 结论

这一步证明了手机/平板集群可以先以“可替换 worker backend”接入 ComfyUI，而不需要修改 TeaCache 或 SageAttention。它还没有证明真实 Android 吞吐；下一阶段应把 loopback transport 换成 USB/10GbE 平板 worker，再测真实 base-return、GPU overlap 和 fallback rate。
