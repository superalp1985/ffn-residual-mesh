# Iteration 67: Exact Q5 and Mixed Gate/Up Residuals

Date: 2026-09-07

## Implementation

Added `FFN_RESIDENT_CENTERED_AFFINE_V2`, with Q4_K or Q5_K selected per
gate/up projection. V1 remains readable. For every group of 32 codes,
`b = ceil((min(q) + max(q)) / 2)` and `r = q - b`. Q5 residuals preserve
all five bits, with range `[-16, 15]`: 16 nibble-pair bytes plus four
high-plane bytes per group. No clipping or requantization is performed.

The CPU evaluates `(alpha*b + beta) * sum(x_group)`; the GPU evaluates
the resident `alpha*r*x` terms. Gate and up are merged before SwiGLU,
then the original quantized down projection is applied.

The grouped and grouped-fused single-flight runners support Q4/Q5 mixtures.
Legacy and tiled Q4-only execution reject incompatible Q5 artifacts.
IQ4_XS, Q3_K and Q6_K gate/up remain uncompiled fallbacks.

## Boundary

Exact residual representation does not imply compression. CPU coefficients
are still read for each input-dependent base result. These measurements do
not establish full-model 8 GiB residency, attention/KV performance, generation
quality, DMA-engine utilization, SM occupancy or 20 tokens/s.
