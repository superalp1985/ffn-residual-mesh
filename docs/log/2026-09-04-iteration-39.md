## Change

## Result

For block=4, 1024-row tiles and 8 CPU threads:

- gate residual max absolute error: `1.10e-7`, relative L2: `1.24e-7`;
- up residual max absolute error: `5.99e-8`, relative L2: `1.23e-7`;
- serial CPU-main + GPU-residual pair: `3.29 ms`;
- concurrent pair: `2.50 ms`;
- measured speedup: `1.31x`.

The persisted artifact, CPU table evaluator and CUDA residual kernel are therefore consistent at the integration boundary. The remaining unmeasured operation is the gate/up SwiGLU/down path.
