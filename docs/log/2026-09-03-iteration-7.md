# 2026-09-03 Iteration 7

## 研究目标修正

本轮根据讨论重新定义目标：

- 目标不是降低 FFN 总 FLOPs，也不是把 FFN 变成简单线性层。
- 目标是把前馈层权重和算子提前展开到 RAM，运行时增加乘加/块合并，减少 GPU 与 CPU 之间动态搬运、显存驻留和等待。
- 查表不是前提；优先研究直接读取预展开块、非查表代数拆分和轻量合并。

## 研究前置

再次核对公开路线后，本轮不复刻通用 LUT-GEMM。已有工作主要解决低比特查表、热/冷神经元或分层调度，没有直接给出适用于现成 Qwen3.5 dense SwiGLU 的“非查表拆分 + 合并”公式。

## 实验一：全局非线性特征公式

测试：

```text
z = P.T @ (x-c)
phi = [1,z,z^2,...,z^d]
y_hat = phi @ C
```

layer 23 的最佳留出 rel-L2 仍约 0.258--0.286；layer 22 更差，约 0.535 以上。固定全局展开点不足以表达所有 SwiGLU 状态，不作为主公式。

双线性交叉特征在 rank 较低时有一定改善，但 rank 增大后训练误差极低、留出误差爆炸，属于过拟合，不作为主公式。

## 实验二：按中间神经元的非查表多项式

公式：

```text
h_j = u_j * p_j((g_j - mu_j) / sigma_j)
y = sum_b W_down,b @ h_b
```

结果：

- layer 23：degree=4 的留出输出 rel-L2 约 0.0283，激活 rel-L2 约 0.0394；degree=3 约 0.0371。
- layer 22：degree=3 的留出输出 rel-L2 约 0.0741，激活 rel-L2 约 0.0644。
- degree=4 只需约 86 KiB(fp16) 的每神经元系数、均值和尺度。

这说明 SiLU 非线性可以拆成离线系数与运行时乘加，且不需要 LUT、不需要运行时调用 SiLU。该结果是“本层合并公式”的候选。

## 实验三：分块低秩权重

测试：

```text
W_b ~= U_b V_b
```

运行时用两次矩阵乘替代一次 dense 矩阵乘，按输出块在 hidden 空间相加。

当前结果：

- down-only、block=512、rank=16：权重存储约减少 32.8%，但留出输出误差约 0.575。
- gate/up-only、block=512、rank=16：权重存储约减少 65.4%，但留出输出误差约 0.747。
- all-three 即使权重减少约 98%，误差仍超过 0.81。
- block=1024、rank=128 的 down-only 误差仍约 0.461，暂不能直接替换。

结论：对原始 dense 权重做简单低秩分解，在当前层和误差门槛下过于激进；不能把“减少权重字节”直接等同于“可部署”。更合理的方向是保留主要权重块精确计算，只对稳定块做拆分，或把多项式非线性公式与少量残差权重块结合。

## 当前结论

1. 非查表公式可行，按中间神经元多项式明显优于全局低维多项式。
2. “拆分运算 + 本层 hidden 维加法合并”已经有候选公式。
3. 权重低秩化不能一次性覆盖整层；下一步应采用分块选择性拆分、精确主干 + 小残差，而不是全量分解。
4. 重点仍是带宽/显存/算力重新分配，不追求减少总计算量。
