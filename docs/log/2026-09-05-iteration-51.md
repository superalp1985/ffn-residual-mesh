# Iteration 51: Qwen3.8-27B asset validation

日期：2026-09-05

## 本轮目标

固定 Qwen3.8-27B GGUF 的真实文件身份、尺寸和 FFN tensor 清单，为离线
resident-residual artifact 编译建立输入契约。

## 调研/验证

- 读取本地 `E:\Qwen3.8-27B\config.json`：`hidden=5120`、
  `ffn=17408`、`layers=64`。
- 使用 `gguf.GGUFReader` 读取 tensor 元数据，不将 16.5GB 文件整体载入
  Python 内存。
- 使用 32MiB 分块流式计算 SHA256。
- FFN 共有 `64 x 3 = 192` 个 tensor。

## 结果

```text
file bytes: 16464440224
sha256: 322e194ff79741c7baa497c240f677f54b201b0efab44ca8e50f122b39123482
types: IQ4_XS=85, Q5_K=50, Q4_K=38, Q3_K=7, IQ4_NL=6, IQ3_S=4, Q6_K=2
```

该文件是混合 `Q4_K_M`，不是所有 tensor 都是 `Q4_K`。因此后续编译器必须
按 tensor type 分派解码器；对尚未支持的 IQ/Q3/Q5/Q6 类型保留 exact
fallback，不允许静默近似。
