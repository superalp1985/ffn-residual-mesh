# 2026-09-03 Iteration 8

## 目标

本轮继续坚持非查表主线：预展开到 RAM，运行时用额外算力换动态权重搬运；不把降低总 FLOPs 或 LUT 查找当目标。

## 研究前置

本轮复核了公开的 SwiGLU/SiLU 近似和低秩矩阵路线，结论是：已有方法可以提供激活近似或矩阵分解工具，但对本项目更关键的是“误差如何映射到实际 FFN 输出、哪些块值得拆”。因此本轮加入真实激活上的选择性权重拆分，而不是只按矩阵 Frobenius 误差排序。

## 实验一：非查表 SwiGLU 多项式

公式：

```text
h_j = u_j * p_j((g_j - mu_j) / sigma_j)
y = sum_b W_down,b @ h_b
```

结果：

- layer 23：按中间神经元拟合，degree=4 的留出输出 rel-L2 约 `0.0283`；degree=3 约 `0.0371`。
- layer 22：degree=3 的留出输出 rel-L2 约 `0.0741`。
- 系数产物约 `86 KiB(fp16)`，不需要查表，也不调用运行时 SiLU。

这一公式适合作为本层非线性合并器，但本身没有消除 gate/up/down 的权重矩阵搬运。

## 实验二：全量分块低秩权重

```text
W_b ~= U_b V_b
```

layer 23 结果：

- down-only、block=512、rank=16：权重约减少 `32.8%`，留出误差约 `0.575`。
- gate/up-only、block=512、rank=16：权重约减少 `65.4%`，留出误差约 `0.747`。
- all-three：即使权重减少约 `98%`，误差仍约 `0.81`。

全量低秩化不可接受，说明增加算力不能无约束换取带宽。

## 实验三：精确主干 + 选择性拆分块

离线按每个块的 SVD 残差排序，只拆满足 `factor_bytes < exact_Q4_bytes` 的块，其余保持精确：

- layer 23、block=512、rank=64、拆分比例约 25% 时，down-only 误差约 `0.249`，权重减少约 `7.1%`；gate/up-only 误差约 `0.252`，减少约 `6.4%`。
- rank=16、拆分比例约 25% 时，down-only 误差约 `0.286`，gate/up-only 约 `0.294`，权重减少约 `9.7%`–`12.4%`。
- 增加拆分块比例后误差快速上升，说明仅按权重矩阵误差选块不够，需要按真实激活的输出敏感度选块。

## 结论

1. 非查表多项式是目前最稳定的“合并公式”候选。
2. 简单全量低秩权重拆分不适合作为主路径。
3. “精确主干 + 选择性低秩块”方向可行，但第一版选择指标不对；Frobenius 误差低不代表 FFN 输出影响低。
4. 权重拆分必须使用激活加权敏感度，例如：

   ```text
   score_b = E_x || (W_b - W_hat_b) a_b(x) ||^2
   ```

   对 gate/up 还要通过 SwiGLU 门控传播；不能只看 `||W_b-W_hat_b||_F`。
