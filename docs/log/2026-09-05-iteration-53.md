`data/resident_qwen38_layer3_exact_v1`

- up residual + alpha;
- total package bytes: `111,411,200`.

Observed:

- first miss: `111,411,200` weight H2D bytes, `10.87 ms` copy event;
- second access: `0` weight H2D bytes, `0 ms` copy event;
- device package bytes after hit: `111,411,200`.

This confirms the package cache behavior for one real Qwen3.8 layer. It does
not measure full FFN latency, attention, KV cache, window prefetch overlap,
or generation throughput. The current cache waits for the copy event before
returning, so it is a correctness baseline rather than an asynchronous
throughput claim.
