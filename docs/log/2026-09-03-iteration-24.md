# 2026-09-03 Iteration 24

## 目标

验证真正的冷启动预展开公式：把 Chebyshev 常数项合成输入到输出的矩阵，只在运行时保留少量高阶 FFN 通道。

```text
y ~= L0 x + Wd_S [u_S * sum(p>=1) c_p T_p(g_S)]
L0 = Wd diag(c0) Wu
```

## 先行调研

- 多项式网络可表示为高阶权重张量；CP/Tucker/Tensor-Train 能压缩这类张量，但最佳低秩分解并不简单，也不能假设按原神经元通道裁剪就等价于张量低秩。
- 因此本轮先做最低成本的必要性检查：按校准集高阶能量与 down 列范数排序，扫描保留通道数。如果没有拐点，就停止通道裁剪并进入跨通道低秩分解。

## 实现

新增 `scripts/evaluate_preexpanded_sparse_cp.py`：

- degree=2，bound=5 sigma。
- 冷启动预计算 `L0`。
- 按 `RMS(nonlinear scalar) * ||Wd column||` 选取 64 到 6144 个高阶通道。
- 估算 fp16 展开 artifact 与每 token MAC。

## 结果

完整 degree-2 多项式重放相对真实捕获 FFN 的 holdout mean rel-L2 为 `5.61%`。

| 保留通道 | 比例 | holdout rel-L2 | fp16 artifact / 原 Q4 FFN | MAC / 三次稠密投影 |
|---:|---:|---:|---:|---:|
| 64 | 1.0% | 107.9% | 37.5% | 12.2% |
| 512 | 8.3% | 97.6% | 60.0% | 19.4% |
| 1,024 | 16.7% | 75.2% | 85.7% | 27.8% |
| 2,048 | 33.3% | 44.9% | 137.2% | 44.4% |
| 4,096 | 66.7% | 15.0% | 240.1% | 77.8% |
| 6,144 | 100% | 5.61% | 343.0% | 111.1% |

线性预展开项单独误差约 `149%`，说明 layer 23 的高阶贡献不是少量异常通道，而是广泛分布在 FFN 维度上。

## 结论

1. 原通道重要度裁剪没有可用拐点，失败。
2. 保留 1/3 通道仍有约 `44.9%` 误差，同时 fp16 artifact 已大于原始 Q4 FFN 权重。
3. 高阶项必须跨通道合并：下一轮使用监督式 CP 特征 `(A^T x) * (B^T x)`，让多个原神经元贡献进入同一低秩乘积通道。
4. `L0` 的 8 MiB fp16 矩阵本身可接受，但只有与强压缩的高阶部分组合才有意义。
