# 2026-09-03 Iteration 13

## 目标

扫描 Chebyshev 基底的区间边界，确认每层是否需要独立选择 degree/bound。

## 调研与参数

本轮继续核对 Chebyshev/Clenshaw 的区间稳定性。采用标准化 gate 值的截断区间 `[-B, B]`，只在离线拟合中改变 `B`，运行时仍是递推乘加。

## 结果

基础项留出输出 rel-L2：

- layer 23：
  - degree=4、B=5：`0.02449`
  - degree=4、B=6：`0.02546`
  - degree=5、B=5：`0.02323`（当前最好）
  - degree=5、B=6：`0.02377`
- layer 22：
  - degree=4、B=5：`0.05082`
  - degree=4、B=6：`0.04999`（当前最好）
  - degree=5、B=7：`0.05009`

接入 capture-target 残差后，layer 23 的 degree=5、B=5：

- 基础项：`0.02323`。
- output_rank=64：`0.02244`。
- top-k=4：`0.02258`，仅 8 B fp16 系数值 + 8 B bitmask，近似路径总计约 `4112 B/token`。
- 95% 校准尾部阈值：约 `98.6%` token 走近似，混合误差约 `0.02206`，期望 H2D 约 `150 KiB/token`。

## 结论

1. Chebyshev 的 `degree/bound` 必须按层选择，统一参数会损失明显误差裕量。
2. layer 23 已出现“约 2.2% 输出误差 + 4 个残差系数”的稳定候选，足以进入真实搬运原型。
3. 增加 degree 从 4 到 5 有收益，但只增加一个逐元素递推项；继续升高 degree 尚未证明值得。
4. layer 22 经过 Chebyshev 已从 7.8% 降到约 4.8%，但仍应设置更严格回退/精确策略。
