# 2026-09-03 Iteration 11

## 目标

验证 CPU 分类残差系数、GPU 常驻基底和精确回退的联合路径。

## 公式

先计算完整残差系数 `alpha(x)`，再按绝对值保留 top-k：

```text
I_k = TopK(|alpha(x)|)
y_approx = y0 + mu_r + sum_{i in I_k} alpha_i(x) U_i
```

传输包可用两种编码：

- `fp16 values + bitmask`：固定 `ceil(output_rank/8)` 字节掩码。
- `fp16 values + uint8 indices`：适合很小的 k。

回退判据：

```text
tail(x) = ||alpha(x) - TopK(alpha(x))||_2
```

阈值由校准集分位数确定；超过阈值走精确 FFN。

## 结果：layer 23

残差目标为 `capture`，base degree=4，`input_rank=128`、`output_rank=64`。

- top-k=4：8 B fp16 系数值 + 8 B bitmask = `16 B`；若用 uint8 索引则为 8 B + 4 B = `12 B`。实际本实验近似路径包含基础输出，总计 `4112 B/token`。
- 不回退时留出 rel-L2：约 `0.02698`。
- top-k=4、校准 95% 分位阈值：留出近似比例约 `97.8%`，混合误差约 `0.02664`，期望 H2D 约 `228 KiB/token`，相对完整 down 权重减少约 `97.8%`。
- top-k=4、校准 99% 分位阈值：近似比例约 `99.3%`，混合误差约 `0.02682`，期望 H2D 约 `77 KiB/token`，减少约 `99.2%`。
- 全部走近似：误差约 `0.02698`，近似路径代理流量约 `4.1 KiB/token`。

## 结果：layer 22 负对照

- top-k=4、校准 95% 分位阈值：混合误差约 `0.07630`。
- 全部走近似：误差约 `0.07708`。

减少搬运不能修复该层的公式失配，因此 layer 22 应直接选择精确路径或更高成本的专用公式。

## 结论

1. CPU top-k 分类确实能把残差系数从 `128 B/token` 压到 `16--24 B/token`，误差变化很小。
2. 尾部能量阈值能在误差预算和回退流量之间提供连续旋钮；但当前 H2D 数字是代理模型，不是 llama.cpp 实测。
3. bitmask/索引开销必须计入，不能只报告系数值字节。
4. 该路径符合“增加 CPU 串行计算，减少 GPU 动态权重搬运”的目标；下一步应做连续 token、超级块和 pinned ring buffer 实测。
