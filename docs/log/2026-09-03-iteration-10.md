# 2026-09-03 Iteration 10

## 目标

验证“按神经元多项式基础项 + 低秩输出残差”的完整公式，并检查残差系数是否需要非线性特征。

## 调研决策

本轮检索重点是 nonlinear low-rank residual、activation-aware approximation、polynomial activation approximation。没有发现可以直接替换本实验的现成 Qwen3.5 FFN 算子；公开路线主要支持动态残差、分层路由和精确回退，而不是整层静态低秩替代。因此继续采用本项目的分层、非查表、可回退路线。

## 公式

基础项：

```text
h0_j = u_j * p_j((g_j - mu_j) / sigma_j)
y0 = W_down @ h0
```

残差项先在输入上做 PCA 投影，再生成系数：

```text
z = P.T @ (x - mu_x)
phi(z) = [z] 或 [z, z^2] 或 [z, z^2, z^3]
r ~= U_r @ alpha(phi(z))
y ~= y0 + r
```

残差目标分两种：

1. `exact`：拟合解量化 `W_down @ h_exact`，追求数学重放。
2. `capture`：拟合采集到的 `ffn_out`，追求量化模型实际行为。

## 结果

模型：Qwen3.5-2B-Q4_K_M；655 个校准样本、138 个留出样本。

layer 23，基础多项式 degree=4：

- 基础项留出 rel-L2：`0.02829`。
- 残差能量占 exact 输出：`0.01779`。
- 拟合 exact 目标时，`input_rank=128, output_rank=64` 留出误差：约 `0.02753`（对 capture）。
- 拟合 capture 目标时，同配置留出误差：约 `0.02671`。
- 残差输入使用 `[z,z^2]` 或三次项没有稳定改善，三次项出现留出过拟合；保留线性系数生成作为默认。

layer 22 负对照：

- degree=4 基础项留出 rel-L2：`0.07833`。
- 拟合 capture 目标、完整 64 个残差系数时仍约 `0.07657`。

## 传输估算

- GPU 常驻输出基底：`output_rank=64` 时约 `256 KiB`。
- 每 token 残差系数：`128 B(fp16)`。
- CPU 基础输出：`4096 B(fp16)`，相对于 layer 23 的 down Q4 权重 `10,321,920 B` 明显更小。

## 结论

1. “多项式基础项 + 低维残差”在 layer 23 已达到可继续做系统原型的精度区间。
2. 残差系数非线性特征不是当前瓶颈，增加次数只增加 CPU 工作和过拟合风险。
3. 残差目标应支持 `exact/capture` 双模式；默认部署评估使用 `capture`，同时保留 exact 结果作为理论参考。
4. layer 22 必须禁用该近似或提高回退等级，不能跨层复用 layer 23 参数。
